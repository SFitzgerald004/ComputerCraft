# Message Send Recieve System
This is a one way message send recieve system. This is mainly used for sending a message out to a general message board to view on a monitor

## Installation
This system comes with an installation script for both readers and senders. Reader clients should be installed on a computer meant to collect and display messages. Sender clients are meant to send out messages to the reader client.

To download the install script, use the following command: `wget https://github.com/SFitzgerald004/ComputerCraft/raw/refs/heads/main/message_send_recieve/install.lua`
