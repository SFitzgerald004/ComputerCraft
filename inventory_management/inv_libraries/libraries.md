### Libraries
These libraries are used by the collector to handle different inventory types. These come with the full collector package, so nothing needs to be done here.

## Currently supported
* Chest

## Planned Support
* Storage Drawers
* Barrels
* Create Inventories
* Power Sources

# Notes
Storage Drawers have the types: 'functionalstorage:xxx, inventory'
Barrels have the types: 'minecraft:barrel, inventory'
Create Fluid Tanks have the types: 'create:fluid_tank, fluid_storage'
