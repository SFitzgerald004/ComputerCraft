# Inventory Management System
This inventory management system allows for users to collect and transmit data over their desired channels to get data about connected inventory systems

## Installation
This system comes with an install file that automatically downloads all necessary files for each client type. Once the install script is executed, the user will be prompted to dictate either a reader or collector installation. Collectors are used on computers that connect to the inventories themselves. Readers are used on the computers where the inventory information is displayed. 

To download the install script, use the following command: `wget https://github.com/SFitzgerald004/ComputerCraft/raw/refs/heads/main/inventory_management/install.lua`
